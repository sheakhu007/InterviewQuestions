# 1. What is the difference between an EC2 instance and an ECS container?
# - EC2 instances are virtual machines that run on AWS hardware, whereas ECS containers are lightweight, portable units that run applications on EC2 instances or using Fargate.

# 2. How does AWS Elastic Beanstalk differ from AWS Lambda?
# - Elastic Beanstalk is a Platform-as-a-Service (PaaS) for deploying and managing applications, while Lambda is a serverless compute service that runs code in response to events without managing servers.

# 3. What is Amazon RDS Read Replica?
# - A read-only copy of the primary RDS database that helps distribute read traffic to improve performance and support high availability.

# 4. How does AWS Athena query data stored in S3?
# - AWS Athena allows you to run SQL queries directly on data stored in S3, using a serverless model and charging per query or data scanned.

# 5. What is Amazon ECS?
# - Amazon ECS (Elastic Container Service) is a fully managed container orchestration service for running Docker containers on EC2 instances or using AWS Fargate.

# 6. What is AWS CloudFormation?
# - AWS CloudFormation automates the process of provisioning AWS resources using templates written in JSON or YAML, enabling infrastructure as code (IaC).

# 7. What is AWS CodeBuild?
# - AWS CodeBuild is a fully managed build service that compiles code, runs tests, and produces deployable artifacts.

# 8. How does Amazon Redshift handle large-scale data processing?
# - Amazon Redshift uses Massively Parallel Processing (MPP) to distribute queries across multiple nodes, providing fast query performance on large datasets.

# 9. What are Spot Fleet Requests in EC2?
# - Spot Fleet allows you to manage and maintain a fleet of Spot Instances, with the ability to specify instance types and allocate capacity based on price and availability.

# 10. What is AWS SQS Long Polling?
# - Long polling allows Amazon SQS to wait for a message to be available in the queue, reducing the number of empty responses and costs associated with short polling.

# 11. What is the difference between RDS Multi-AZ and Read Replicas?
# - RDS Multi-AZ is for failover and high availability, while Read Replicas are used to scale read operations by distributing the load across additional databases.

# 12. What is Amazon CloudWatch Logs?
# - Amazon CloudWatch Logs allows you to monitor, store, and access log data from AWS services, applications, and other systems for real-time visibility.

# 13. How does AWS Elastic Load Balancer (ELB) distribute traffic?
# - ELB distributes incoming traffic to multiple targets (like EC2 instances) across different availability zones, improving availability and fault tolerance.

# 14. What is Amazon Route 53 Latency-Based Routing?
# - Latency-based routing directs user requests to the region with the lowest network latency to improve response times for global users.

# 15. What is AWS Step Functions?
# - AWS Step Functions orchestrates microservices and tasks using visual workflows, making it easier to coordinate distributed applications and track states.

# 16. How does Amazon Kinesis Data Streams handle real-time data?
# - Kinesis Data Streams captures and processes large streams of real-time data with applications such as analytics, log processing, and machine learning.

# 17. What is the difference between EBS and EFS?
# - EBS (Elastic Block Store) provides block storage for EC2 instances, while EFS (Elastic File System) offers shared, scalable file storage accessible from multiple instances.

# 18. What is the purpose of Elastic Network Interfaces (ENIs)?
# - ENIs provide additional network interfaces that can be attached to EC2 instances, enabling multiple IP addresses, security groups, and network configurations.

# 19. How does AWS Auto Scaling determine when to scale resources?
# - AWS Auto Scaling uses predefined scaling policies based on metrics such as CPU utilization, memory usage, and custom CloudWatch alarms to adjust the number of instances.

# 20. What is AWS DMS?
# - AWS Database Migration Service (DMS) helps migrate databases to AWS securely with minimal downtime, supporting homogeneous and heterogeneous migrations.

# 21. What is Amazon Redshift Spectrum?
# - Redshift Spectrum allows you to query data stored in S3 without having to load it into Redshift, enabling a more flexible, cost-efficient data lake architecture.

# 22. How does Amazon Cognito secure user authentication?
# - Cognito provides user sign-up, sign-in, and access control with multi-factor authentication, token-based authentication, and integration with external identity providers.

# 23. What is the purpose of Amazon API Gateway throttling?
